# Mots-clés et plan de contenu

## Méthode (gratuite)

1. **Search Console** (dès la mise en ligne) : source principale. Repérer les requêtes avec
   impressions mais peu de clics → améliorer `title` et `description`.
2. **Suggestions Google** et « Autres questions posées » : relever les formulations réelles
   (« … avis », « … vaut-il le coup », « … ou … »).
3. **Google Trends** (France) : comparer l'intérêt entre modèles pour prioriser les fiches et sélections.
4. **Forums** (Forumamontres, Reddit) : questions récurrentes = sélections et guides à créer.
5. Noter les cibles retenues ci-dessous, avec la page qui y répond.

## Familles de requêtes

| Famille          | Modèle de requête                                | Volume attendu        | Concurrence       | Page                |
| ---------------- | ------------------------------------------------ | --------------------- | ----------------- | ------------------- |
| Prix modèle      | `prix <marque> <modèle>`                         | Moyen                 | Revendeurs        | Fiche               |
| Référence        | `<référence>`                                    | Faible, très qualifié | Faible            | Fiche               |
| Avis modèle      | `<modèle> avis`                                  | Moyen                 | Magazines, forums | Fiche               |
| Sélection budget | `montre automatique moins de <prix> euros`       | Élevé                 | Magazines         | Sélection           |
| Sélection usage  | `montre plongée`, `montre chronographe <budget>` | Élevé                 | Forte             | Sélection           |
| Comparaison      | `<modèle A> vs <modèle B>`                       | Faible à moyen        | Faible            | Comparateur         |
| Nouveautés       | `nouveautés <marque> <année>`                    | Saisonnier            | Moyenne           | Nouveautés          |
| Calibre          | `calibre <nom>`                                  | Faible                | Faible            | Calibre (plus tard) |

La **longue traîne** (références, comparaisons, combinaisons modèle + intention) est le terrain le
plus accessible pour un nouveau site : peu de concurrence, intention d'achat claire.
